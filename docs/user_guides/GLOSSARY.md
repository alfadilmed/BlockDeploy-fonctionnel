# Glossaire Web3 BlockDeploy

Bienvenue dans le glossaire Web3 de BlockDeploy ! Cet espace est conçu pour vous aider à comprendre les termes techniques que vous rencontrerez fréquemment dans le monde de la blockchain, des cryptomonnaies et des contrats intelligents.

Naviguez par ordre alphabétique ou utilisez la fonction de recherche de votre navigateur (Ctrl+F ou Cmd+F) pour trouver un terme spécifique.

---

## A

*   **Adresse (Address):** Une chaîne unique de caractères alphanumériques qui identifie un compte ou un contrat intelligent sur une blockchain. Exemple : `0x123...def`.
*   **Airdrop:** Une distribution gratuite de tokens ou de NFTs à un groupe d'adresses de portefeuille.
*   **API (Application Programming Interface):** Une interface qui permet à deux logiciels de communiquer entre eux.
*   **Arbitrum:** Une solution de "Layer 2" pour Ethereum pour des transactions plus rapides et moins chères.

## B

*   **Blockchain:** Un registre numérique décentralisé, distribué et immuable.
*   **Bloc (Block):** Un ensemble de transactions enregistrées et confirmées sur la blockchain.
*   **BNB Smart Chain (BSC):** Une blockchain compatible EVM, connue pour ses transactions rapides et ses frais bas.
*   **Burn (Brûler):** Détruire définitivement des tokens. Réduit la supply totale.
*   **Bytecode:** Le code de bas niveau d'un smart contract déployé sur l'EVM.

## C

*   **Cap (Plafond):** Pour un token ERC-20 "Capped", la supply maximale absolue de tokens.
*   **Chain ID:** Un identifiant numérique unique pour chaque réseau blockchain.
*   **CID (Content Identifier):** Un identifiant unique utilisé par IPFS pour référencer des fichiers.
*   **Contrat Intelligent (Smart Contract):** Un programme auto-exécutable stocké sur une blockchain.

## D

*   **DAO (Decentralized Autonomous Organization):** Une organisation gérée par du code et contrôlée par ses membres.
*   **DApp (Decentralized Application):** Une application qui fonctionne sur un réseau décentralisé.
*   **Décimales (Decimals):** Pour un ERC-20, le nombre de chiffres après la virgule. 18 est standard.
*   **DeFi (Decentralized Finance):** Un écosystème d'applications financières sur blockchains.
*   **Déploiement (Deployment):** Le processus de publication d'un smart contract sur une blockchain.

## E

*   **ERC-20:** Un standard pour les tokens fongibles sur Ethereum et réseaux EVM.
*   **ERC-721:** Un standard pour les NFTs uniques sur Ethereum.
*   **ERC-1155:** Un standard multi-token (fongibles et non fongibles).
*   **Ethereum:** Une plateforme blockchain décentralisée pour smart contracts. Ether (ETH) est sa cryptomonnaie.
*   **EVM (Ethereum Virtual Machine):** L'environnement d'exécution des smart contracts sur Ethereum et compatibles.
*   **Explorateur de Blocs (Block Explorer):** Un site web (ex: Etherscan) pour visualiser les infos de la blockchain.

## F

*   **Frais de Réseau (Network Fees):** Voir "Gas".
*   **Fongible (Fungible):** Interchangeable avec un autre du même type/valeur (ex: ERC-20).

## G

*   **Gas:** L'unité mesurant le travail de calcul pour les opérations blockchain.
*   **Gas Limit:** Quantité maximale de gas pour une transaction.
*   **Gas Price:** Prix par unité de gas (en Gwei).
*   **Gouvernance (Governance):** Processus de prise de décision dans un projet décentralisé/DAO.
*   **Gwei:** Une petite dénomination de l'Ether (1 ETH = 10^9 Gwei).

## I

*   **Immuable (Immutable):** Une donnée sur la blockchain ne peut être modifiée/supprimée.
*   **IPFS (InterPlanetary File System):** Système de stockage de fichiers décentralisé (pour métadonnées/médias NFT).

## L

*   **Layer 1 (L1):** La blockchain principale (ex: Ethereum).
*   **Layer 2 (L2):** Solution construite sur une L1 pour améliorer sa scalabilité (ex: Polygon, Arbitrum).

## M

*   **Mainnet (Réseau Principal):** Version "live" d'une blockchain (transactions à valeur réelle).
*   **MetaMask:** Un portefeuille Web3 populaire (extension navigateur/mobile).
*   **Métadonnées (Metadata):** Pour un NFT, les informations descriptives (nom, image, attributs).
*   **Mint (Frapper / Émettre):** Création de nouveaux tokens sur la blockchain.

## N

*   **NFT (Non-Fungible Token):** Token cryptographique représentant un actif unique.
*   **Nœud (Node):** Un ordinateur participant au réseau blockchain.
*   **Nonce:** Numéro associé à chaque transaction d'une adresse, assurant l'ordre.
*   **Non Fongible (Non-Fungible):** Unique, non remplaçable par un autre identique (ex: NFT).

## O

*   **Optimism:** Une solution Layer 2 pour Ethereum (Optimistic Rollups).
*   **OpenZeppelin:** Fournisseur de bibliothèques de smart contracts standardisés et sécurisés.
*   **Owner (Propriétaire):** Adresse avec droits administratifs sur un contrat `Ownable`.

## P

*   **Pausable:** Fonctionnalité d'un contrat permettant au propriétaire de geler temporairement certaines actions (ex: transferts).
*   **Polygon (PoS):** Plateforme de scaling pour Ethereum (sidechain EVM). Cryptomonnaie MATIC.
*   **Portefeuille (Wallet):** Logiciel/matériel pour stocker et gérer des crypto-actifs.
*   **Pré-compilé (Precompiled Contract):** Contrat intelligent avec bytecode déjà généré, prêt à déployer.
*   **Provider RPC (RPC Provider):** Service fournissant un point d'accès (URL RPC) à un nœud blockchain.
*   **Proof of Stake (PoS):** Mécanisme de consensus basé sur la mise en jeu (stake) de tokens.
*   **Proof of Work (PoW):** Mécanisme de consensus basé sur la puissance de calcul (minage).

## R

*   **Royalties (Redevances NFT):** Pourcentage du prix de revente d'un NFT versé au créateur original (standard EIP-2981).
*   **RPC (Remote Procedure Call):** Protocole pour exécuter du code sur un serveur distant (nœud blockchain).

## S

*   **Scalabilité (Scalability):** Capacité d'un système à gérer un volume croissant de transactions.
*   **Sepolia:** Un réseau de test (Testnet) public pour Ethereum.
*   **Solidity:** Langage de programmation pour smart contracts sur EVM.
*   **Supply (Offre):** Quantité totale d'un token. (Total Supply, Max Supply, Circulating Supply).

## T

*   **Testnet (Réseau de Test):** Version d'une blockchain pour tests (tokens sans valeur réelle).
*   **Token:** Un actif numérique émis sur une blockchain.
*   **Transaction (Tx):** Une opération signée soumise à la blockchain.
*   **Transaction Hash (Tx Hash / TxID):** Identifiant unique d'une transaction.

## W

*   **Wallet:** Voir "Portefeuille".
*   **Wei:** La plus petite unité d'Ether (1 ETH = 10^18 Wei).
