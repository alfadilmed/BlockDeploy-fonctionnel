## L2-M5.2: Mises à Jour de la Documentation Utilisateur (Lot 2: ERC-20 MVP & Polygon)

**Objectif:** Identifier le contenu à ajouter/mettre à jour dans la documentation utilisateur (Mini-Academy, Guides, FAQ).

### 1. Nouveau Guide Utilisateur: "Déployer votre Token ERC-20 Personnalisé"
*   **Cible:** Utilisateurs créant un ERC-20.
*   **Contenu:**
    *   Intro ERC-20, cas d'usage, avantages BlockDeploy.
    *   Prérequis (wallet, fonds testnet, gas).
    *   Étapes de Création (avec captures d'écran du formulaire L2-M4.1):
        1.  Accès Formulaire.
        2.  Infos Générales Projet: Nom projet, Choix Réseau (incluant Polygon, implications).
        3.  Config Token ERC-20:
            *   Identité: Nom, Symbole (conventions), Décimales (18, fixe MVP).
            *   Supply: "Fixe" vs "Plafonnée (Capped)". Champs "Supply Initiale", "Plafond Max" (expliquer conversion wei).
            *   Fonctionnalités: "Burnable", "Pausable" (expliquer implications).
        4.  Récapitulatif & Déploiement: Importance vérification, estimation gas (si feature présente), bouton "Déployer".
    *   Après Déploiement: Notifications, retrouver contrat sur Dashboard, infos affichées (adresse, hash, lien explorateur), interagir sur Polygonscan/Etherscan.
    *   FAQ ERC-20 MVP: Changer supply? Propriétaire? Ajouter à MetaMask?
