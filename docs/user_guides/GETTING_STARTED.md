## 4. Questions Fréquemment Posées (FAQ pour Débutants)

*   **Q: Qu'est-ce que le "gas" ou les "frais de réseau" ?**
    *   R: Le gas est une petite quantité de la cryptomonnaie native d'une blockchain (comme l'ETH pour Ethereum ou MATIC pour Polygon) que vous payez pour effectuer des opérations sur le réseau, comme déployer un contrat ou transférer des tokens. Ces frais rémunèrent les validateurs qui sécurisent le réseau. BlockDeploy vous donnera une estimation de ces frais avant chaque déploiement.

*   **Q: Pourquoi mon déploiement prend-il du temps ?**
    *   R: Une fois que vous soumettez une demande de déploiement, elle est envoyée à la blockchain. La vitesse à laquelle elle est traitée et confirmée dépend de l'encombrement du réseau et des frais de gas que vous avez acceptés. Cela peut prendre de quelques secondes à plusieurs minutes. Vous pouvez suivre le statut dans votre Dashboard BlockDeploy.

*   **Q: Où puis-je voir mon contrat une fois déployé ?**
    *   R: Votre contrat sera listé dans votre Dashboard BlockDeploy sous "Mes Contrats". De plus, pour chaque déploiement réussi, nous vous fournirons un lien direct vers un explorateur de blocs (comme Etherscan ou Polygonscan) où vous pourrez voir toutes les informations publiques de votre contrat sur la blockchain.

*   **Q: Est-ce que BlockDeploy stocke mes clés privées ?**
    *   R: Non. Vous interagissez avec BlockDeploy via votre propre portefeuille Web3 (comme MetaMask). BlockDeploy ne vous demandera jamais votre clé privée ou votre phrase secrète. Pour les déploiements de contrats, vous signez les transactions directement dans votre portefeuille.
