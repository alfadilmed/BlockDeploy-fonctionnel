# Comprendre les Tokens ERC-20

## Qu'est-ce qu'un Token ERC-20 ?
ERC-20 est un standard technique pour les tokens fongibles (interchangeables) sur la blockchain Ethereum et les réseaux compatibles EVM. Si un token respecte ce standard, il peut être facilement échangé et interagir avec d'autres applications et portefeuilles compatibles ERC-20.

## Caractéristiques Clés d'un ERC-20
*   **Nom (Name):** Ex: "MyToken"
*   **Symbole (Symbol):** Ex: "MTK"
*   **Décimales (Decimals):** Généralement 18, définit la divisibilité.
*   **Total Supply:** La quantité totale de tokens existants.
*   **Fonctions Standard:** `transfer`, `balanceOf`, `approve`, `transferFrom`, etc.

## À Quoi Servent les Tokens ERC-20 ?
*   **Monnaie d'un Projet:** Pour les DApps, jeux, plateformes.
*   **Tokens d'Utilité (Utility Tokens):** Donnent accès à un service ou produit.
*   **Tokens de Gouvernance (Governance Tokens):** Donnent des droits de vote dans une DAO.
*   **Représentation d'Actifs:** Peut représenter des actions, des points de fidélité, etc.
