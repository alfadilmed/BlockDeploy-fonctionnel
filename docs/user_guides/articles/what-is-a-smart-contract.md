# Qu'est-ce qu'un Smart Contract ?

## Introduction
Un contrat intelligent (ou "smart contract" en anglais) est un programme informatique auto-exécutable qui s'active lorsque des conditions prédéfinies sont remplies. Il est stocké et exécuté sur une blockchain, ce qui le rend transparent, immuable et digne de confiance.

## Comment ça Marche ?
*   **Code sur la Blockchain:** Le logique du contrat est écrite en code (ex: Solidity pour Ethereum).
*   **Déclencheurs:** Des événements ou des transactions peuvent déclencher l'exécution du contrat.
*   **Exécution Automatique:** Une fois déclenché, le contrat exécute automatiquement les termes codés.
*   **Sans Intermédiaire:** Élimine souvent le besoin d'un tiers de confiance.

## Cas d'Usage Courants
*   Finance Décentralisée (DeFi)
*   Tokens (ERC-20, NFT)
*   Organisations Autonomes Décentralisées (DAO)
*   Gestion de la chaîne d'approvisionnement
*   Systèmes de vote
